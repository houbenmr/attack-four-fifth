Research code accompanying the paper "Computing endomorphisms of superspecial principally polarized abelian surfaces in time and memory p^{4/5+o(1)}"

attack.m contains a proof-of-concept magma implementation of Algorithm 2

IKO_experiment.sage generates the experimental data for Section 9

analyze_norms.sage generates the corresponding figures

sample_from_distributions.sage compares the three distributions on {1,...,X} weighted by 1, a2(n), and b2(n) respectively.

We slightly modified the AVIsogenies package (avisogenies/), as well as the code from KLPT2 (external/lib/) for our purposes.

The original AVIsogenies code is by Gaetan Bisson, Romain Cosset, and Damien Robert.
https://gitlab.inria.fr/roberdam/avisogenies

The original KLPT2 code is by Wouter Castryck, Thomas Decru, Peter Kutas, Abel Laval, Christophe Petit, and Yan Bo Ti.
https://github.com/KLPT2/KLPT2
